# Sales Performance Dashboard – Power BI

##  Project Overview

This project is an interactive Sales Performance Dashboard built using Microsoft Power BI.

The dashboard analyzes sales, profit, orders, products, regions, categories, and salespeople to help understand business performance and identify important trends.

##  Business Objectives

- Monitor overall sales and profit performance
- Analyze monthly sales trends
- Identify top-performing products
- Compare sales across regions
- Compare different product categories
- Analyze salesperson performance
- Track profit margin and average order value
- Provide interactive filtering for business analysis

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV Dataset

##  Dashboard KPIs

The dashboard includes:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Profit Margin %
- Average Order Value

##  Dashboard Analysis

### Executive Sales Overview
- Monthly Sales Trend
- Sales by Region
- Sales by Category
- Top 10 Products by Sales
- Sales vs Profit by Category

### Salesperson Performance
- Sales by Salesperson
- Total Sales
- Total Profit
- Total Orders
- Profit Margin %

##  Interactive Filters

Users can filter the dashboard using:

- Date
- Region
- Category
- Sales Channel

All visuals and KPI cards respond dynamically to the selected filters.

##  Dataset

The project uses a synthetic sales dataset containing 15,000 sales transactions from 2025.

The dataset includes information about:

- Orders
- Customers
- Regions
- States and Cities
- Salespeople
- Products
- Categories
- Quantity
- Sales
- Cost
- Profit
- Payment Mode
- Sales Channel
